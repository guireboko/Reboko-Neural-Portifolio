# Reboko Neural Portfolio

Portfólio interativo em React que representa a mente criativa de Reboko como um ambiente neural 3D. A proposta é mostrar projetos, habilidades e experiências de forma cinematográfica, unindo desenvolvimento web, inteligência artificial, design e narrativa visual.

## Conceito

A experiência principal do site é baseada na ideia de entrar na mente do desenvolvedor.

O usuário acessa o portfólio, vê uma cena neural em 3D e é convidado a explorar as áreas do cérebro digital. Cada área representa uma parte importante da trajetória: projetos, habilidades, experiência, forma de trabalhar com IA e contato.

A evolução planejada é transformar essa cena inicial em uma animação mais avançada, com:

- avatar 3D representando Reboko;
- luz entrando pelo olho do avatar;
- câmera viajando para dentro da cabeça;
- cérebro interativo funcionando como hub do portfólio;
- projetos surgindo como memórias ou conexões neurais.

## Objetivo do projeto

Este projeto foi criado para demonstrar:

- capacidade de desenvolver interfaces modernas;
- domínio de React e ecossistema front-end;
- criatividade em UX/UI;
- uso prático de IA no processo de criação;
- organização de projetos reais em portfólio;
- visão de produto e apresentação profissional.

## Projetos destacados

### thIAgo — Assistente Virtual de Gestão de Acessos

Assistente virtual especializado em IAM SAP, criado para apoiar analistas na resolução de chamados com base em documentação interna e histórico de atendimentos.

### Reboko Yupoo API — Catálogo Integrado

Base reutilizável para catálogos conectados ao Yupoo, com layout moderno, filtros, paginação e estrutura preparada para diferentes vendedores.
